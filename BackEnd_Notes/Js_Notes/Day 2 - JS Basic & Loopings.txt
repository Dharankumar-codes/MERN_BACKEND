1. TRUTHY AND FALSY VALUES

============================================================

NOTES:

In JavaScript, every value can behave like true or false when it is

used inside a condition. A value that behaves like true is called a

Truthy value. A value that behaves like false is called a Falsy value.

Truthy and Falsy values are mainly useful when working with if

conditions, logical operators and validations. JavaScript automatically

converts the given value into a Boolean value while checking a condition.

-------------------------

FALSY VALUES

-------------------------

JavaScript has these common falsy values:

false

0

-0

""

''

null

undefined

NaN

Example:

if(0) {

console.log("True");

} else {

console.log("False");

}

Output:

False

Example:

let name = "";

if(name) {

console.log("Name Available");

} else {

console.log("Name Not Available");

}

Output:

Name Not Available

-------------------------

TRUTHY VALUES

-------------------------

Most values other than falsy values are Truthy.

Examples:

true

1

-1

10

"hello"

" "

[]

{}

[1, 2]

{ name: "Bala" }

Example:

if("hello") {

console.log("Truthy Value");

}

Output:

Truthy Value

IMPORTANT:

"0" is Truthy because it is a String.

0 is Falsy because it is a Number.

Example:

console.log(Boolean(0)); // false

console.log(Boolean("0")); // true

console.log(Boolean("")); // false

console.log(Boolean("Hello")); // true

console.log(Boolean(null)); // false

console.log(Boolean([])); // true

console.log(Boolean({})); // true

2. DIFFERENCE BETWEEN VAR, LET AND CONST

============================================================

NOTES:

var, let and const are keywords used to create variables in JavaScript.

The main differences between them are redeclaration, reassignment and

scope. var is the older way of declaring variables, while let and const

were introduced in ES6.

Use let when the value needs to change later. Use const when the

variable should not be reassigned. In modern JavaScript, const and let

are generally preferred over var.

-------------------------

VAR

-------------------------

Syntax:

var variableName = value;

Example:

var name = "Bala";

Redeclaration is allowed:

var name = "Bala";

var name = "Kumar";

console.log(name);

Output:

Kumar

Reassignment is allowed:

var age = 20;

age = 25;

console.log(age);

Output:

25

var is Function Scoped.

Example:

if(true) {

var a = 10;

}

console.log(a);

Output:

10

-------------------------

LET

-------------------------

Syntax:

let variableName = value;

Example:

let age = 20;

Redeclaration is NOT allowed:

let age = 20;

let age = 25;

Error

Reassignment is allowed:

let age = 20;

age = 25;

console.log(age);

Output:

25

let is Block Scoped.

Example:

if(true) {

let a = 10;

}

console.log(a);

Output:

Error

-------------------------

CONST

-------------------------

Syntax:

const variableName = value;

Example:

const country = "India";

Redeclaration is NOT allowed.

const country = "India";

const country = "USA";

Error

Reassignment is NOT allowed.

const country = "India";

country = "USA";

Error

const is Block Scoped.

-------------------------

QUICK DIFFERENCE

-------------------------

var

- Redeclaration -> Yes

- Reassignment -> Yes

- Scope -> Function Scope

let

- Redeclaration -> No

- Reassignment -> Yes

- Scope -> Block Scope

const

- Redeclaration -> No

- Reassignment -> No

- Scope -> Block Scope

Best Practice:

const -> Default choice

let -> Use when value changes

var -> Avoid in modern JavaScript when possible

3. INCREMENT AND DECREMENT

============================================================

NOTES:

Increment is used to increase a number and decrement is used to decrease

a number. These operators are very important in looping because the loop

needs to move from one value to another.

++ increases the value by 1 and -- decreases the value by 1.

Increment:

let a = 1;

a++;

console.log(a);

Output:

2

Decrement:

let a = 5;

a--;

console.log(a);

Output:

4

Other ways:

a = a + 1;

a += 1;

a++;

All can be used to increase the value.

4. FOR LOOP

============================================================

NOTES:

A loop is used to execute the same block of code repeatedly. Instead of

writing the same statement many times, we can use a loop and control how

many times the code should execute.

The for loop is commonly used when we know how many times the code needs

to run. A for loop contains three important parts: initialization,

condition and increment/decrement.

Syntax:

for(initialization; condition; increment/decrement) {

// code

}

Example:

for(let i = 1; i <= 5; i++) {

console.log(i);

}

Output:

1

2

3

4

5

============================================================

5. HOW FOR LOOP WORKS

============================================================

Consider:

for(let i = 1; i <= 5; i++) {

console.log(i);

}

Step 1:

let i = 1

Initialization happens only once.

Step 2:

i <= 5

Condition is checked.

Step 3:

console.log(i)

Loop body executes.

Step 4:

i++

Value increases.

Step 5:

Condition is checked again.

Flow:

Initialization

↓

Condition

↓

true?

/ \

yes no

↓ ↓

Code Stop

↓

Increment

↓

Condition Again

============================================================

be processed.

}

8. MULTIPLE VALUE OUTPUT

============================================================

Multiple value output means generating more than one value or building

multiple values during the loop.

One common example is multiplication tables.

Example:

let num = 5;

for(let i = 1; i <= 10; i++) {

console.log(num + " x " + i + " = " + (num * i));

}

Output:

5 x 1 = 5

5 x 2 = 10

5 x 3 = 15

5 x 4 = 20

5 x 5 = 25

5 x 6 = 30

5 x 7 = 35

5 x 8 = 40

5 x 9 = 45

5 x 10 = 50

============================================================

9. SUM USING LOOP

============================================================

Sometimes a loop needs to calculate and store a result instead of

simply printing values.

For this, create a variable outside the loop and update it during

every iteration.

Example:

let sum = 0;

for(let i = 1; i <= 5; i++) {

sum = sum + i;

}

console.log(sum);

Calculation:

0 + 1 = 1

1 + 2 = 3

3 + 3 = 6

6 + 4 = 10

10 + 5 = 15

Output:

15

============================================================

10. STRING BUILDING USING LOOP

============================================================

A loop can also create multiple values in the same line by storing

them inside a variable.

Example:

let result = "";

for(let i = 1; i <= 5; i++) {

result = result + i + " ";

}

console.log(result);

Output:

1 2 3 4 5

11. PATTERN PROGRAM

============================================================

NOTES:

Pattern programs are useful for understanding how loops repeat values

and how output is constructed. Before learning nested loops, students

should first understand how to create a pattern using one loop.

We normally create an empty string, add a value during each iteration

and print the final result.

Example:

let pattern = "";

for(let i = 1; i <= 5; i++) {

pattern = pattern + "*";

}

console.log(pattern);

Output:

*****

13. NESTED FOR LOOP

============================================================

NOTES:

A nested loop means placing one loop inside another loop. The outer loop

usually controls rows and the inner loop controls columns. For every one

execution of the outer loop, the inner loop completes all of its

iterations.

Nested loops are important for pattern programs, tables, matrices,

two-dimensional arrays and grid-based logic. Understanding rows and

columns is the easiest way to understand nested loops.

Syntax:

for(let i = 1; i <= rows; i++) {

for(let j = 1; j <= columns; j++) {

// code

}

}

Outer Loop:

i -> Row

Inner Loop:

j -> Column

14. UNDERSTANDING NESTED LOOP

============================================================

for(let i = 1; i <= 3; i++) {

for(let j = 1; j <= 3; j++) {

console.log(i, j);

}

}

Output:

1 1

1 2

1 3

2 1

2 2

2 3

3 1

3 2

3 3

Explanation:

When:

i = 1

Inner loop:

j = 1

j = 2

j = 3

Then:

i = 2

Inner loop starts again:

j = 1

j = 2

j = 3

Then:

i = 3

Inner loop:

j = 1

j = 2

j = 3
