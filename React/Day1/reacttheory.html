React Basics – Reading / Theory Tasks

TASK 1 – REACT BASICS

1. What is React?

React is a JavaScript library used to build user interfaces. It was developed by Facebook, now called Meta.

2. Why do we use React?

We use React to create interactive and reusable user interfaces. It helps us build web applications easily using components.

3. Is React a library or framework?

React is a JavaScript library, not a complete framework. It mainly focuses on building the user interface.

4. What are the main features of React?

  • Components
  • JSX
  • Virtual DOM
  • Reusable UI
  • Declarative UI
  • One-way data flow

5. What is a Single Page Application (SPA)?

A Single Page Application is a web application where the page does not completely reload when the user moves between different sections. React can update only the required part of the page.

6. What is declarative UI?

Declarative UI means we tell React what the user interface should look like, and React handles updating the UI when the data changes.

TASK 2 – COMPONENTS

1. What is a Component in React?

A component is a small and reusable part of a React user interface. For example, Navbar, Button, Header, and Footer can be components.

2. Why do we use Components?

We use components to divide a large application into small and manageable parts. Components can also be reused in different places.

3. What is a Functional Component?

A functional component is a JavaScript function that returns JSX and displays a part of the user interface.

4. What is Component-Based Architecture?

Component-Based Architecture means building an application by dividing the user interface into separate components.

5. What is a Component Tree?

A Component Tree shows how React components are connected to each other. A parent component can contain child components.

6. Why should component names start with a capital letter?

Component names start with a capital letter so React can identify them as custom components instead of normal HTML elements.

7. What is a reusable component?

A reusable component is a component that can be used multiple times in different parts of an application.

TASK 3 – JSX

1. What is JSX?

JSX stands for JavaScript XML. It allows us to write HTML-like code inside JavaScript.

2. Why do we use JSX in React?

JSX makes it easier to create and understand the user interface. It allows us to write HTML-like structure and JavaScript together.

3. Is JSX HTML?

No. JSX looks similar to HTML, but it is not HTML. JSX is a syntax extension for JavaScript.

4. How do we write JavaScript expressions inside JSX?

We use curly braces to write JavaScript expressions inside JSX.

Example: 

const name = "Dharan";

return (
    <h1>Hello {name}</h1>
);

5. Why do we use className instead of class?

In JSX, we use className instead of class because class is a JavaScript keyword. The className property is used to add CSS classes to an element.

6. What is React Fragment?

React Fragment allows us to group multiple JSX elements without adding an extra HTML element to the DOM.

Example:

<>
    <h1>Hello</h1>
    <p>Welcome to React</p>
</>

7. What are the important JSX rules?

  • JSX must have one parent element.
  • Use className instead of class.
  • Close all HTML tags.
  • Use camelCase for many attributes.
  • Use curly braces for JavaScript expressions.
  • Component names should start with a capital letter.

TASK 4 – DOM, VIRTUAL DOM & RECONCILIATION

1. What is DOM?

DOM stands for Document Object Model. It represents the HTML document as a tree of objects that JavaScript can access and change.

2. What is Virtual DOM?

Virtual DOM is a lightweight JavaScript representation of the actual DOM. React uses it to determine what parts of the UI need to be updated.

3. What is the difference between DOM and Virtual DOM?

The DOM is the actual structure of the web page in the browser. The Virtual DOM is a JavaScript representation used by React to compare UI changes before updating the actual DOM.

4. What is Reconciliation in React?

Reconciliation is the process React uses to compare the previous UI with the new UI and update the necessary parts of the DOM.

5. What is Diffing?

Diffing is the process of comparing the old Virtual DOM with the new Virtual DOM to find what has changed.

6. How does React identify changes in the UI?

React creates a new Virtual DOM when the state or props change. It compares the new Virtual DOM with the previous one and finds the changes.

7. Why is key important while rendering lists?

A key helps React identify each item in a list. It allows React to understand which items were added, removed, or changed.
