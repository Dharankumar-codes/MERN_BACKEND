JavaScript Basics

Introduction to JavaScript

JavaScript is a programming language mainly used to add behavior and interaction to websites. It can respond to user actions and change the content of a web page.

JavaScript is a synchronous and single-threaded language. This means it normally processes one statement at a time in the order in which the code is written.

Example:

console.log("Welcome to JavaScript");

What is a Statement?

A statement is a complete instruction that tells JavaScript to do something.

Example:

let studentName = "Arun";
console.log(studentName);

In this example, the first statement creates a variable and the second statement displays its value.

What is an Expression?

An expression is a piece of code that is evaluated to produce a value.

Example:

15 + 25

The value produced by this expression is 40.

What is Control Flow?

Control flow describes the order in which JavaScript runs different statements in a program.

In normal execution, JavaScript starts from the first statement and continues toward the next statements. 

console.log("Start");
console.log("Processing");
console.log("Finish");

What is a Condition?

A condition is a comparison or expression that gives one of two results: true or false.

Example:

let marks = 75;

marks >= 50

Since the marks are 75, the condition evaluates to true.

if Statement

The if statement is used to execute a block of code only when a specified condition is true. 

let marks = 80;

if (marks >= 50) {
    console.log("Student passed");
}

Here, the message is displayed because the marks are greater than or equal to 50.

if...else Statement

The if...else statement allows us to choose between two different blocks of code. 

let number = 7;

if (number % 2 === 0) {
    console.log("Even number");
} else {
    console.log("Odd number");
}

If the condition is true, the first block runs. Otherwise, the code inside the else block runs.

Conclusion

JavaScript provides statements, expressions, conditions and control-flow statements that help us create interactive and dynamic web pages.
